# Rimero: Batalhas de Rima

crie um simulador de carreira de batalhas de rima, o "rimero". o jogo vai se passar no cenario brasileiro, faça a identidade visual como da primeira imagem (pode fazer um pouco mais bonito mas tente n colocar muitas coisas q deixem na cara q eh ia; mantenha a logo). dai qnd apertar vai pra uma tela de selecionar qual estado quer representar (se possivel com as bandeirinhas), nome e sonho (Duelo Nacional de Mcs, Aniversário da Aldeia ou Seguir na carreira musical), dai qnd for iniciar vai pra uma tela estilo da segunda foto (n faça igual, so use de inspiração e tb aplique a nossa identidade visual), dai como é de rima n vai ter valor, só idade (tb faz escolher no inicio esqueci) e o overall, dai vai ter convites de batalhas de acordo com o estado q colocou (p n dar mt trabalho no inicio coloque so batalhas genericas) e enquanto vai avançando vai atualizando a outra tela (vai ter batalhas, vitorias e folinhas); dai faça uns eventos de vez em quando pro jogador escolher entre coisas q tem chance de dar bom e dar ruim ou n fazer nada e n ter nenhum efeito
